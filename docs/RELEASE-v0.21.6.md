# v0.21.6 — 左上角 BEST 行再下移，彻底让开分数

v0.21.5 已把 BEST 从 116.4 下移到 122.4，但真机上仍被反馈“分数被最高分挡住”。
这版把间距直接翻倍，并同步下移 Boss 卡，避免压线。

## 改了什么

- **BEST 行**：122.4 → **130.4**（相对 1920 参考坐标），与 50 号分数框底 **114.8** 留 **15.6**。
- **GRAZE 行**：顺延到 **155.4**。
- **底板**：高度 142 → **154**（纵向 24–178）。
- **Boss 卡**：顶部 168.8 → **180.8**，与底板仍留 2.8；面板内部排版不变。
- BEST 数值与标签同一基线，不再额外上提 3px。
- 仅 HUD，不动玩法、数值与 Boss 行为。
