# v0.18.0 — 全面对标网页版（手感 / Boss / 平衡 / 界面排列）

这一版不新增玩法，目标是让 Unity 版**玩起来就是网页版那一个游戏**。
方法是对着冻结在 `web/www/js/` 的原版逐行核对，而不是凭手感调参。
数值门禁从 281 条涨到 **425 条**，并首次引入**行为断言**。

## 三个真 bug（"武器没劲、手感发飘"的根因）

1. **蓄能按帧扣而不是按枪扣** —— `WeaponSystem.Tick()` 每帧扣一次，等于把 `drain`
   放大到帧率倍：pulse LV1 应 7.4/s，实测约 53/s。两秒打空 → 长期失谐 → 伤害长期 ×0.55。
   现在开销集中在 `ChargeCost()` 纯函数、在 `TryFire()` 里按枪扣；门禁断言
   `cost / interval == drain`，任何"顺手改回每帧"都会立刻红。
2. **换线不清停留计时** —— 原版每次换线把 `swapIdle` 归零，Unity 只累加，
   于是 1.2 秒共鸣门槛永远满足，连按 1/2/3 就能刷满 5 层共鸣（+40% 伤害）。
3. **通关分算两遍** —— `BossController.Die()` 已按原版公式结算，
   `Director.OnBossDefeated()` 又加一次 `500×(区号+1)`。补偿作为 Unity 独有增强保留，
   但改成结算面板里看得见的「星区补偿」一行。

## Boss：22 招重做

旧实现是 Unity 自己发明的一套招式名与序列，和原版只对得上三四招，且一帧放完。

- 攻击模型换成原版状态机：0.5 秒预告（`TELL_TIME`）→ 出招后按 `at(时刻, 动作)` 分节拍
  → 按阶段间隔收招；连续弹幕（螺旋 / 陨星 / 双旋）走每帧发射器。
- 22 招逐条按 `entities.js:2076-2432` 重写：扇形三段、环爆三层、双生扫射两条错峰光束、
  十字光牢、母舰召唤（按星区换兵表）、重弹压制、双子光矛、雷区播种、相位闪现、
  星网绞杀、波动弹幕、裂隙光幕（缺口 4 个青环预告 + 两排针弹）、星脉脉冲、
  贯穿冲撞（0.9/1.5/2.2/3.2 四段机体运动）、光牢旋扫、陨星暴雨（7 列走动安全道 + 三层弹速）、
  猎群连射、逆向双旋、环形雷阵、新星爆发（闪白 + 震屏 + 三环）。
- 出招间隔 0.85 / 0.62 / 0.42 秒 + 三阶段链招 0.16 秒；**难度系数只作用于弹速**，
  不再污染间隔（标准难度下原本恒定 1.35 秒，Boss 出手慢一倍多）。
- 弹速补阶段系数 1.00/1.06/1.18（`BossBulletSpeedDiv` 原本是死代码）。
- 判定改椭圆：玩家弹 `size×1.02 / ×0.82`（原为圆，纵向胖 34%，Boss 掉血偏快），
  接触椭圆按各台尺寸 76/80/82 计算。
- 换阶段清零破防槽；破防结束立刻补一招；临界（<12%）一次性触发 + 收招白送环弹。

## 关卡平衡与血量

- 敌机判定半径 = `size × 0.78`（美术不变），敌弹命中改**线段扫掠**，修掉高速针弹穿人。
- 俯冲锁定玩家位置并 ×1.5 速；正弦摆幅恢复；悬停/环绕 16 秒后离场；侧掠横穿出屏；
  机体按原版做视觉偏转。
- 分裂幼体半血；母舰 55% 幼体 / 45% 俯冲蜂、3.6 秒固定间隔；装甲词缀补体型 ×1.06 与射速 ×1.12；
  精英蓄力 ×0.8。
- 水雷真减速（`exp(-3.8dt)`）+ 引信 + 10 破片；波动弹接上正弦；追踪弹"只追 N 秒 + 角度限速"。
- 预警 3.0 秒并清场清弹；通关 4.4 秒幕间；换区 1.5 秒无敌；开局 1.6 秒无敌；
  时间奖励按整区用时；清场必掉全套；陨石 80% 掉 2 宝石。
- 打击停顿 / 慢镜（精英 25ms、受创 50ms+0.3s@0.5、星爆 100ms+0.4s@0.45、
  Boss 破防/换阶段/崩解各有档位）。
- 相位穿越只在冲刺 0.17 秒内成立（原先任何无敌帧都能刷星爆与分数）。
