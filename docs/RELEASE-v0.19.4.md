# v0.19.4 — Boss 真的会还手了，僚机能凑三种，两处文字不再叠

## 1. Boss 还是不出招（第二层原因）

v0.19.3 只修了「破防期间攒槽」，但更关键的一层没改：**破防时整段 Update 被早退**。

原版的 `broken` 只做两件事：取消当前招式、受伤 ×1.35。机体照常悬停，**出招计时照常走**。
早退等于每 4 秒静默 1.2 秒——加上首招间隔被写成 2.2 秒（原版 1.15），
玩家看到的就是「它站在那儿不动」。

修法：

- 破防不再 return，只递减眩晕计时；眩晕结束把冷却压到 0.55 秒；
- 破防触发时取消进行中的招式（对应原版 `attack = null`），但时钟不清零；
- 首招间隔 2.2 → 1.15 秒（原版 `attackCd`）。

探针实测（`-boss -probe`）：20 秒内依次放出 **扇形齐射 → 裂隙光幕 → 双子光矛 → 雷区播种**，
敌弹峰值 83 发；修前两次出招间隔 4.6～6.5 秒。

## 2. 僚机永远只有一种

`RestoreDrone()` 传的 `kind = null`，`Bind()` 默认 `"gunner"`——三个挂点全是同一种，
`lance / aegis / swarm` 永远拿不到。改为优先补「当前没有的种类」，三个挂点能凑三种；
选型抽成 `GameConfig.PickDroneKind()` 并加门禁断言。

## 3. 顶部分数压住 BEST

62 号字塞进 52 高的框，字高溢出压到 BEST 行（原版是 24.8 CSS）。
字号降到 50，BEST / GRAZE 改成跟着实测字高排队。

## 4. 底部武器名压住等级条

19 号字塞进 20 高的框，笔画压在 5 格等级条上。名字改 18 号 + 22 高框，等级条下移到 +58。
