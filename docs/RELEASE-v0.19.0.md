# v0.19.0 — 美术重制第一步：18 张机体与 Boss 换成 Blender 渲染

v0.18.0 把玩法与界面对齐了网页版；这一版开始解决"长得不够精致"。
做法不是换手绘图，而是**在 Blender 里真建模，正交顶视渲成透明 PNG**，
再用 PIL 烘一圈同色外发光（定稿风格：3D + 外发光）。

## 换装范围（18 张）

- 玩家三线：`player_pulse` / `player_prism` / `player_swarm`（512²）
- 12 种敌机：drifter / wasp / lancer / orbiter / splitter / bulwark /
  rock / sniper / minekeeper / sidewinder / carrier / shardling（384²）
- 3 台 Boss：gatekeeper / weaver / helios（640²，另有独立 `_ring` 旋转层）

每张都出 `beauty` + `_mask`（受击闪白用的白剪影）；文件名、画布档位、`.meta`/guid 全部不变，
所以 **C# 一行没改**，`ShipArt` 的 PPU/pivot/0.46 外接半径约定由渲染端自动满足。

## 管线（`artgen/blender/`）

- `gen_art.py`：正交顶视相机 + 四点布光（key / fill / rim / under），Cycles GPU（OptiX）
  无头渲图；硬表面由 `poly_prism`（任意 2D 轮廓沿 Z 挤出 + 倒角）拼装，参数全在代码里，可复现。
- `post_glow.py`：alpha 高斯模糊染色做外发光，**alpha 上限 0.45**——不能渗进
  0.50 的轮廓阈值，否则视觉半径会超过判定圈。
- `check_art.py`：逐张断言画布档位 / 居中偏差 / 外接半径比（0.42–0.52，旧手绘图实测就有 0.51）/
  有效像素占比 / mask 与 beauty 的形状 IoU ≥ 0.95。

## 三个踩过的坑

1. **霓虹用 Principled 的自发光口会被轮廓光打成纯白**：420W 面光在发光条上的镜面反射
   直接削顶到 1.0，色相全丢。改用纯 Emission 着色器（对布光免疫），强度压到 1.1–1.4。
2. **几何包围盒 ≠ 视觉外接框**：薄片与发光边会差好几像素。改为「渲 160px 小样 → 量 alpha
   外接框与半径 → 反推缩放位移」，每张图自动落到 0.46，不靠手调。
3. **敌机机头朝下、玩家机头朝上**：两套轮廓方向不同，玩家机若按敌机写就会上下颠倒
   （这一版真发生过，靠 `flip_180` 绕世界 Z 转 180° 修正）。
