# v0.21.0 — 设计走查 P0：敌机分色、弹幕硬边、底板去圆角

## 1. 敌机不再是"同一个银白盾形"

`build_from_spec()` 之前只把机种色用在霓虹条上，机体一律默认深金属，
`EnemyDefs` 里 12 个 Tint 一个都没进画面。现在机体 = Tint × 0.26、装甲 = Tint × 0.45：
玫红（drifter/splitter）、紫（lancer/sidewinder）、青（sniper）、金（minekeeper）、
灰（rock/bulwark/carrier）—— 混战里能靠颜色区分解法。

## 2. 弹幕形状语言统一

| | 之前 | 现在 |
|---|---|---|
| 玩家弹 | 细长胶囊 | **短粗实心菱形**（青/玫/金） |
| 敌弹 | 柔边圆斑（视觉 ≈ 判定 2.5×） | **硬边空心环 + 亮芯**（≈1.3×） |

敌我靠**形状**区分（实心 vs 空心），不再只靠颜色；同时按视觉契约把外缘压到判定的 1.4 倍以内。

## 3. 分数底板

圆角矩形 → 硬边切角 + 1px 描边。
