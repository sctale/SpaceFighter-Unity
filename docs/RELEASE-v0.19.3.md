# v0.19.3 — 修三个真 bug 与一批文字遮挡

## 玩法（两个真 bug）

1. **脉冲侧翼子弹打不到人**
   `FirePulse` 的横向速度 ±45 / ±85 / ±105 是「原版像素/秒」，却直接当世界单位喂给了
   `BulletPool.Spawn`（少乘 `Px`）。实际横飞 2400+ px/s，一帧就出屏——只有正中间那发
   能命中，所以玩家看到的是「子弹在飞但打不中」。修好后三叉/四叉/星瀑的斜向弹才真的有效。

2. **Boss 永久破防、几乎不出招**
   破防槽在眩晕期间仍然累积（原版只在 `broken <= 0` 时攒）。槽满 → 眩晕 1.2s →
   醒来第一发又立刻触发下一轮，持续输出就能把 Boss 锁死。运行时探针实测：两次出招之间
   空了 4.6 秒，全靠间隙漏弹幕。现在眩晕期间不攒槽。

## 新增调试能力

`SpaceFighter.exe -probe`（配合 `-shots`/`-quit`）每 0.5 秒输出一行遥测：
状态、分数、玩家弹数、敌弹数、蓄能、Boss 血量/阶段/是否出招/招式名。
这次的两个玩法 bug 就是靠它从「感觉不出招」变成「日志里 casting 一直为 false」的。
