# v0.20.1 — 分数不再压 Boss 面板、Boss 不再被打断、敌机与 Boss 低模化

## 1. 左上角分数与 Boss 面板重叠

分数底板高 176（下沿到 98 CSS），Boss 面板从 84.4 CSS 开始；
再加上为避刘海整体下移了 24，压得更狠。
→ 不再整体下移，底板缩到 130 高（下沿 78 CSS），与 Boss 面板留 12 的缝。

## 2. Boss 的攻击会被打断

破防触发时会 cancel 当前招式（原版也如此），但玩家持续输出下**每 4 秒破防一次**，
招式永远放不完 → 看起来"不会还手"。
→ 破防不再打断招式（保留受伤 ×1.35 与提示）；破防门槛 `max(60, 18%)` → `max(90, 30%)`，
破防回归成"奖励"而不是"每 4 秒的沉默"。

## 3. 小兵与 Boss 低模化

`gen_art.py` 增加 `LOWPOLY_STYLE`：粗糙度 0.80、Specular 0.15、曝光 −0.30、
key/rim 削到 0.8/0.4。12 种敌机 + 3 台 Boss（含环层）全部重渲，
与 Polyfork 玩家机统一成哑光平面语言。
