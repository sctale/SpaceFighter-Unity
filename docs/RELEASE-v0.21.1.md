# v0.21.1 — 背景加第二层星云与星点亮度分档

设计走查 P1 的开头：背景原本是单层渐变 + 140 颗亮度接近的星点，看起来像色卡。

## 做了什么

- **星云层**：5 团 9–22 世界单位的柔光云，按星区色染色（alpha 0.055–0.095），
  纵向 0.16/s 漂移、轻微横摆，出屏从顶部回卷；`sortingOrder -60` 压在星点之下。
- **星点三档亮度**：每颗带 0.35–0.8 随机亮度，约 12% 为亮星（尺寸 ×1.9、alpha 1.0）。
  前后层次靠"大小 + 亮度"两条轴一起拉开，而不是只靠速度。
