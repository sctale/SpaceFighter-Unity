# v0.19.5 — Boss 不再被秒杀，左上角分数稳定可读

## Boss 被秒杀：三个原因叠在一起

| # | 问题 | 修法 |
|---|---|---|
| 1 | **入场期可以被打**（原版 `hit()` 里 `entering` 直接 return） | `BossController.Entering` + `CanTakeDamage()`，就位前不结算 |
| 2 | **穿透弹对同一目标每帧重复结算** | 给每颗弹加 `HitBoss` 标记，一颗弹对 Boss 只打一次 |
| 3 | 标记的复位写进了 `Tick()`，每帧清零等于没加 | 只在 `Init()` 复位 |

探针实测（强制棱镜 L5）：

- 修前：t=5.4 开始掉血（Boss 5.9 才就位）→ 5.9 秒时已归零，**1.5 秒打空 400 血**
- 修后：入场全程 400/400 → 就位后 4.1 秒打完，掉血速率 ~130 dps（98 dps × 对巨构加成）

## 左上角分数被挡住：渐变方向写反了

`Texture2D` 的 `y = 0` 是**底行**，我却把「顶带」写成底边不透明——
结果它不是渐变，而是一块**边缘硬切的暗带**。这才是"分数被盖住"反复修不掉的真因。

实测像素（同一列自顶向下）：修前 y=147 与 y=152 之间差 6 个色阶的硬边；
修后 (4,7,16) → (6,11,23) → (8,14,30) 连续过渡，底带同理。

另外：分数块加了一层 alpha 0.34 的淡底板，敌机从背后掠过时四行字仍然可读；
顶部留 12px 最小安全边，刘海/挖孔屏不会贴边。

## 新增调试参数

```bash
SpaceFighter.exe -shots -boss -probe -quit -weapon prism -lvl 5
```

`-weapon` 切武器线、`-lvl` 定等级，配合 `-probe` 能直接量 Boss 的 TTK 与 DPS 曲线。
