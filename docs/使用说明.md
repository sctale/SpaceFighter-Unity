# Aurora Rift（Unity 重构版）使用说明

## 直接玩

- **Android**：安装根目录 `AuroraRift-Unity-v0.15.0.apk`（Android Debug 签名，允许"未知来源"即可）。
- **Windows**：`Builds\Windows\SpaceFighter.exe`。
- 用手机竖屏或窗口比例接近 9:16 的桌面窗口效果最好。

> v0.15.0 起舰船全部换成独立美术：玩家三条武器线三套涂装、12 种敌机、3 类僚机、
> 3 台 Boss（本体 + 旋转环 + 呼吸光环）、7 类弹体与 4 类补给箱图标。
> 想单独看美术可打开 `artgen/preview.png`。

## 操作

| 动作 | 桌面 | 触屏 |
|---|---|---|
| 移动 | 鼠标拖动 / 方向键 / WASD | 按住拖动 |
| 精准模式（慢速+收束+判定点） | 按住 `Shift` | 按住右下角圆形「精准」环 |
| 切换武器线 | `1` 脉冲 / `2` 棱镜 / `3` 蜂群 | —（桌面键位） |
| 星爆 NOVA（满 100） | `空格` | — |
| 棱镜力场（消耗 1 护盾，8 秒吞弹+挡一次致命） | `Q` 或鼠标右键 | — |
| 暂停 | `P` / `Esc` | — |
| 重开（阵亡后） | 点击 / `R` | 点击 |

> 移动端目前只有"移动 + 精准"两套触控；切武器/NOVA/力场还没做屏幕按钮，需要的话我可以按同样风格补。

## 调试参数（桌面）

```bash
SpaceFighter.exe -zone 6            # 直接从第 6 星区（恒星）开局
SpaceFighter.exe -screen-width 540 -screen-height 960 -screen-fullscreen 0
SpaceFighter.exe -shots -autoshot -zone 5 -tag zone5   # 定时截图到 docs/shots
SpaceFighter.exe -boss -zone 1      # 跳过波次直接打该星区的 Boss
```

游戏内调试键：`F1/F2/F3` 巡航/标准/深渊，`F5` 下一星区，`F6` 轻柔特效，`F7` 高对比敌弹。

## 规则速览

- 三条武器线共享蓄能：开火掉、收纳回；打空会**失谐**（威力 55%、射速下降），直到回满。
- 换到蓄能健康的线会叠**共鸣**（每层 +8%，最多 5 层），停手 1.2 秒后开始衰减。
- 护盾最多 3 层、开局 1 层；受击先掉护盾，掉光掉舰体，受伤掉当前武器一级。
- 补给箱 4 类：武器升级 / 僚机补回 / 护盾 +1 / 三线回充；连续 3 次没出你缺的，第 4 次强制补。
- 每个星区 3 波，第 3 波进 Boss；Boss 66% / 33% 换阶段（清屏 + 冲击波 + 横幅）。
- 击破结算：基础分 + 时间奖励 + 无伤 1500 + 擦弹奖励（上限 1500）。

## 开发

```bash
# 数值门禁（构建前必跑）
Unity.exe -batchmode -quit -projectPath <proj> -executeMethod AuroraRift.EditorTools.VerifyNumbers.Run

# Windows
Unity.exe -batchmode -quit -projectPath <proj> -executeMethod AuroraRift.EditorTools.BuildScript.BuildWindows

# Android：导出 + 手工 Gradle（详见 docs/PORTING.md）
Unity.exe -batchmode -quit -projectPath <proj> -buildTarget Android \
  -executeMethod AuroraRift.EditorTools.BuildScript.ExportAndroidProject
```
