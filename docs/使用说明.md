# Aurora Rift（Unity 重构版）使用说明

## 直接玩

- **Android**：安装根目录 `AuroraRift-Unity-v0.18.0.apk`（Android Debug 签名，允许"未知来源"即可）。
  桌面图标是深空底 + 青色菱形环 + 舰船的自适应图标（Android 8+ 不再是白底方块）。
- **Windows**：`Builds\Windows\SpaceFighter.exe`。
- 用手机竖屏或窗口比例接近 9:16 的桌面窗口效果最好。

> v0.17.0 把界面按网页版重做：开始菜单（品牌菱形 + 大标题 + 特性胶囊 + 战绩卡 + 难度三选 +
> 渐变主按钮 + 六条操作提示）、战斗 HUD（SCORE/SECTOR 题头、连锁盒、THREAT Boss 卡、
> 底部仪表带 + 三枚动作环）、暂停页与结算页（评级圆章 + 十项数据）。
> 流程补了星区开场 / WARNING / PHASE / CORE BREAK / OVERLOAD / SIGNAL LOST 公告，
> 难度按 `entities.js` 逐条对齐敌机弹幕，另加了应用图标。

## 操作

| 动作 | 桌面 | 触屏 |
|---|---|---|
| 移动 | 鼠标拖动 / 方向键 / WASD | 按住拖动（抓取偏移 + 抬升，单指锁定） |
| 精准模式（慢速+收束+判定点） | 按住 `Shift` / `Ctrl` | 按住右下角「精准」环 |
| 冲刺穿弹 | `空格` | 点「冲刺」环 |
| 星爆 NOVA（满 100） | `X` / `J` | 点「星爆」环 |
| 切换武器线 | `1` 脉冲 / `2` 棱镜 / `3` 蜂群 | 点「换线 · 脉冲」胶囊循环 |
| 棱镜力场（消耗 1 护盾，8 秒吞弹+挡一次致命） | `Q` 或鼠标右键 | 拾到力场箱自动生效 |
| 暂停 | `P` / `Esc` | 右上角 `II` |
| 重开（阵亡后） | 点击 / `R` | 点击 |

三个动作环同时显示状态：精准（按住时高亮）、冲刺（冷却读秒）、星爆（蓄能百分比，满了显示「星爆」）。
切后台或失焦会自动暂停并清掉触屏状态。

## 调试参数（桌面）

```bash
SpaceFighter.exe -zone 6            # 直接从第 6 星区（恒星）开局
SpaceFighter.exe -screen-width 540 -screen-height 960 -screen-fullscreen 0
SpaceFighter.exe -shots -autoshot -zone 5 -tag zone5   # 定时截图到 docs/shots
SpaceFighter.exe -boss -zone 2      # 跳过剧本直接打该星区的 Boss
SpaceFighter.exe -dump              # 打印当前所有在画的 SpriteRenderer（查"界面多出个东西"）
SpaceFighter.exe -rebuild           # 自检「重新开始」链路（拆树重建后各系统是否在线）
SpaceFighter.exe -laser -boss -zone 2 -shots -autoshot # 直接放一次扫射光束拍照
```

游戏内调试键：`F1/F2/F3` 巡航/标准/深渊，`F5` 下一星区，`F6` 轻柔特效，`F7` 高对比敌弹。

## 规则速览

- 三条武器线共享蓄能：开火掉、收纳回；打空会**失谐**（威力 55%、射速下降），直到回满。
- 换到蓄能健康的线会叠**共鸣**（每层 +8%，最多 5 层），停手 1.2 秒后开始衰减。
- 护盾最多 3 层、开局 1 层；受击先掉护盾，掉光掉舰体，受伤掉当前武器一级。
- **开局没有僚机**（只能从补给箱拿，最多 3 架），脉冲线 2 级、另两条线未解锁。
- 补给箱 10 类：武器升级 / 护盾 / 僚机 / 棱镜解锁 / 蜂群解锁 / 力场 / 舰体 / 宝石 / 换线 / 宝石簇；
  连续 3 次没出你缺的，第 4 次强制补。
- **每个星区一段剧本**：12~17 条固定编队（V 字/横排/弧/钳形/狙击巢/雷线/母舰群）逐条出现，
  剧本放完清场，清完才出 Boss；剧本里还埋着武器强化、中期补给和僚机箱。
- Boss 66% / 33% 换阶段（清屏 + 冲击波 + 横幅 + 喘息窗口），招式按固定序列循环、可背板；
  二阶段起招式间隙还会补针弹，不会站着不动。
- 击破结算：基础 4000 + 900×星区 + 时间奖励（剩余秒数×40）+ 无伤（1200 + 200×星区）+ 擦弹×20，
  再乘难度系数。

## 开发

```bash
# 数值门禁（构建前必跑）
Unity.exe -batchmode -quit -projectPath <proj> -executeMethod AuroraRift.EditorTools.VerifyNumbers.Run

# Windows
Unity.exe -batchmode -quit -projectPath <proj> -executeMethod AuroraRift.EditorTools.BuildScript.BuildWindows

# Android：导出 + 手工 Gradle（详见 docs/PORTING.md）
Unity.exe -batchmode -quit -projectPath <proj> -buildTarget Android \
  -executeMethod AuroraRift.EditorTools.BuildScript.ExportAndroidProject
```
