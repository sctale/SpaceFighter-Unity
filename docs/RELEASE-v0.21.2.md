# v0.21.2 — 击杀碎片、补给箱方箱化与 UI 压线清理

设计走查 P1-2 + P2 的收尾版本：把"打爆一架飞机只有一圈光"补成有碎片的击破，
把最后一套圆角胶囊资产（补给箱）换成低模方箱，并修掉分数块 / Boss 卡 / 暂停结算卡的压线。

## 做了什么

### 打击感

- **击杀碎片** `Debris.cs`：5 种缓存多边形碎片，按机体尺寸随机挑片；
  普通 4 片、精英/堡垒/母舰 7 片，Boss 崩解 14 + 3×5 片，玩家坠机 8 片。
  碎片带初速、阻尼、自转、缩小与二次方淡出；低特效模式减半。
- **击破重闪**：重目标额外 0.1 秒白闪 + 0.09 震屏，配合原有的 25ms 顿帧。
- **敌机尾焰**：非陨石机种挂同色柔光尾喷（17/21 Hz 双频抖动），悬停机体不再像贴纸。
- **受击边缘泛色**：力场金 / 护盾紫 / 舰体玫红，屏幕边缘 0.62 alpha × 0.18 秒；中心不遮挡。

### 一致性

- **补给箱**：9 个箱子由六边形徽章改为切角方箱（0.24 切角）+ 四条霓虹边条 + 四角压条，
  图徽抬到 z=0.155–0.195；`check_art` 11/11 通过。
- **棱镜/蜂群**：各补 8 个装甲分件（脊背压板、尾板、翼根进气、翼炮/翼梁、铆点），
  总零件数 18–22，与脉冲机同档。
- **数字等宽**：`AuroraCJK` 的 0–9 advance 均为 555/1000，已实测；SCORE/BEST 不再抖动。
