### 三个必要调整

1. **主装甲要按面积找，不是按面数**：深灰机体 `plating` 有 1680 面，
   但真正的装甲是深红 `hull`（472 面、面积最大）。按「面积 × 饱和度」加权才能挑对；
   灰色件饱和度为 0，自动排除。挑中后按武器线染成青 / 玫 / 金，`trim` 染成亮一档。
2. **低模要压高光**：原布光会把平面打到整片泛白、块面感消失。
   这个资源曝光 −0.55、key/rim 0.7/0.35、粗糙度 0.82、Specular 0.15。
3. **外发光降强度**：亮色低模不需要 0.5 的光晕，降到 0.34，否则轮廓被糊掉。

图标：`gen_icon.py` 读新机体，提亮 16% → 4%。
